# SVG 수학 이미지 에디터

Next.js 16 기반의 강력한 SVG 수학 그래프 및 도형 에디터입니다. 수학 함수 그래프를 그리고, 다양한 도형을 생성하며, 배경 이미지 위에 그림을 그릴 수 있습니다.

## 주요 기능

### 좌표 시스템
- X, Y 좌표축 표시
- 조절 가능한 그리드 시스템
- 눈금 및 좌표 레이블

### 함수 그래프
- **1차 함수**: y = ax + b
- **2차 함수**: y = ax² + bx + c
- **고차 다항식**: 3차, 4차, 5차 이상의 다항식
- **삼각함수**: sin, cos, tan
- **지수/로그 함수**: e^x, ln(x)
- **이차곡선**: 타원, 쌍곡선, 포물선

### 도형 그리기
- 선 (Line)
- 원 (Circle)
- 사각형 (Rectangle)
- 타원 (Ellipse)
- 다각형 (Polygon)
- 텍스트 블록
- 치수선 (Dimension Line) - 거리 표시
- 각도 표시 (Angle) - 직각/일반각

### 편집 기능
- **도형 이동 및 변형**
  - 드래그 앤 드롭으로 도형 전체 이동
  - 각 점을 개별적으로 선택하여 드래그
  - 도형 크기 조절 및 모양 변형
- **실행 취소/다시 실행**
  - Ctrl+Z로 실행 취소 (Undo)
  - Ctrl+Y로 다시 실행 (Redo)
  - UI 버튼으로도 조작 가능
- **도형 삭제**
  - Delete 또는 Backspace 키로 선택된 도형 삭제
  - 전체 클리어 버튼으로 모든 도형/함수 삭제
- **캔버스 조작**
  - 캔버스 크기 드래그 조절 (우측 하단 핸들)
  - 마우스 휠로 줌 인/아웃 (10% ~ 500%)
  - 줌 컨트롤 UI (줌인/줌아웃/리셋 버튼)
  - 좌표축 표시/숨기기 토글
- **텍스트 입력**
  - 실시간 입력 및 폰트 크기 조절
  - Enter로 완료, ESC로 취소
- **도형 그리기 미리보기**
  - 도형을 그릴 때 점선으로 미리보기 표시
  - 직선, 원, 사각형, 타원 등 모든 도형 지원

### 킬러 기능: 배경 이미지
- 배경 이미지 업로드
- 이미지 표시/숨기기 토글
- 기존 도형 이미지를 따라 그리기 가능
- 이미지를 참고하여 정확한 그래프 작성

## 시작하기

### 개발 서버 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 에디터를 사용하세요.

### 프로덕션 빌드

```bash
npm run build
npm start
```

## 사용 방법

### 1. 도형 그리기
1. 왼쪽 툴바에서 원하는 도구 선택
2. 캔버스에서 클릭하여 도형 생성
3. 다각형의 경우 더블클릭으로 완성

### 2. 함수 그래프 추가
1. 오른쪽 패널에서 함수 타입 선택
2. 계수를 쉼표로 구분하여 입력 (예: 1,0,0)
3. 색상 선택
4. "함수 추가" 버튼 클릭

### 3. 텍스트 입력
1. "텍스트" 도구 선택
2. 캔버스에서 원하는 위치 클릭
3. 점선 박스가 나타나면 텍스트 입력
4. 폰트 크기 조절 가능
5. Enter로 완료, ESC로 취소

### 4. 치수선 그리기
1. "치수선" 도구 선택
2. 첫 번째 점 클릭 (시작점)
3. 두 번째 점 클릭 (끝점)
4. 타원형 점선과 거리가 자동으로 표시됨

### 5. 각도 표시
1. "각도" 도구 선택
2. 첫 번째 점 클릭 (꼭지점 - 빨간색)
3. 두 번째 점 클릭 (첫 번째 선)
4. 세 번째 점 클릭 (두 번째 선)
5. 각도 호와 각도 값이 자동으로 표시됨

### 6. 도형 편집
1. "선택" 도구 활성화
2. 도형을 클릭하여 선택
3. 파란색 점을 드래그하여 모양 변경
4. 도형 전체를 드래그하여 위치 이동

### 7. 캔버스 크기 조절
1. 캔버스 오른쪽 하단의 파란색 삼각형 핸들 찾기
2. 핸들을 드래그하여 원하는 크기로 조절
3. 최소 400x300px, 최대 2400x1600px

### 8. 배경 이미지 사용
1. "이미지 업로드" 버튼으로 배경 이미지 추가
2. "이미지 보기/숨기기" 버튼으로 토글
3. 배경 이미지를 참고하여 도형 그리기

### 9. 줌 기능 사용
1. **마우스 휠**: 캔버스 위에서 마우스 휠로 줌 인/아웃
2. **줌 컨트롤 UI** (왼쪽 하단):
   - `+` 버튼: 줌 인
   - `-` 버튼: 줌 아웃
   - `1:1` 버튼: 줌 리셋 (100%)
3. 줌 범위: 10% ~ 500%
4. 좌표축, 함수, 도형 모두 동일하게 확대/축소

### 10. 실행 취소 및 삭제
1. **실행 취소/다시 실행** (왼쪽 하단):
   - `↶` 버튼 또는 Ctrl+Z: 실행 취소
   - `↷` 버튼 또는 Ctrl+Y: 다시 실행
2. **도형 삭제**:
   - 도형 선택 후 Delete 또는 Backspace 키 누르기
3. **전체 클리어**:
   - `🗑` 버튼 클릭하여 모든 도형과 함수 삭제

### 11. 좌표축 표시/숨기기
1. 툴바의 "표시 설정" 섹션
2. "좌표축 보기/숨기기" 버튼 클릭
3. 도형만 깔끔하게 볼 때 유용

## 키보드 단축키

| 단축키 | 기능 |
|--------|------|
| Delete / Backspace | 선택된 도형 삭제 |
| Ctrl+Z | 실행 취소 (Undo) |

| ESC | 텍스트 입력 취소 |

## 함수 입력 예제

| 함수 타입 | 수식 | 계수 입력 예 |
|----------|------|------------|
| 1차 함수 | y = 2x + 1 | 2,1 |
| 2차 함수 | y = x² - 2x + 1 | 1,-2,1 |
| 3차 함수 | y = x³ + 2x² - x + 1 | 1,2,-1,1 |
| 사인 | y = sin(x) | 1,1,0,0 |
| 코사인 | y = 2cos(x) | 2,1,0,0 |
| 지수 | y = e^x | 1,1,0 |
| 타원 | 중심(0,0), a=3, b=2 | 0,0,3,2 |
